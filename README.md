# 灯下百戏 · 借影搭桥

一款以北京皮影戏为题材的双角色悬疑解谜游戏。戏灯刚灭，白幕背后响了三下。一张泛黄的戏单把阿照和拾影带回一场没有演完的戏。玩家独自操纵两人，轮流在台前、幕后寻找线索。

## 下载与开始

[下载最新电脑版单文件](https://github.com/Zhuzhu101029/dengxia-baixi/raw/refs/heads/main/dist/desktop.html)。建议在电脑上用 Chrome 打开下载好的 HTML。三关、图片、音效和序章书法均随文件提供，下载后可以断网游玩，无需安装或解压。等黑屏序章的最后一句写完，点击画面入戏。

## 游玩说明

| 操作 | 按键或手势 |
| --- | --- |
| 走动 | ← → 或 A、D 左右走，↑ ↓ 或 W、S 在当前台面内调整前后位置 |
| 查看或使用物件 | 走到物件旁，按 E 或空格。等角色做完动作，再观察特写里的线索 |
| 切换阿照与拾影 | Q。点亮戏灯后即可切换 |
| 查看装备 | I 或 B。选中两件线索可以尝试拼合，带着拼好的物件去找吻合的轮廓 |
| 调整机关 | 在椅轨、灯轨或窗轴的特写中用左右键微调，也可以用鼠标拖动 |
| 观察和返回 | 在全景里按住鼠标拖动可环视。Esc 退出当前特写、合上背包，或从戏台打开菜单 |

**三关怎么玩**　第一关，从后台的灯架开始，留意椅轨、灯座和幕上的桥影。第二关，沿着刚接好的影桥去东岸，找到失去声音的铃。第三关，把铃留下的线索带到戏衣箱，调查窗棂和残袖。同一处若暂时没有反应，可以换个人物或回装备里比一比形状。

游戏会将进度保存在当前浏览器中。续玩时用同一浏览器打开同一位置的文件。戏台菜单里的「重开」可以从头开始。
